# Learning Recon Report — ScanMe (Nmap + Nikto)

**Date:** July 22, 2026  
**Analyst:** Tatiana  
**Tools Used:** Nmap, Nikto  
**Target:** scanme.nmap.org (legal test target)  

---

## 1. Objective

This exercise was intended to practice reconnaissance and service identification on a safe, legal target. It was a learning activity, not a production assessment or a confirmed vulnerability disclosure. The goal was to practice how to read command output, interpret service information, and document findings clearly.

---

## 2. Tools and workflow

- Nmap was used to identify open ports and services.
- Nikto was used to review web-related indicators and possible configuration weaknesses.
- Findings were documented as part of a learning report.

---

## 3. Scanner observations

The results below are scanner output and should be treated as indicators for further review, not as confirmed vulnerabilities.

- HTTP service detected
- Possible missing security-related headers
- Possible configuration issues worth validating
- Web server behavior observed during scanning
- HTTP methods and service banners reviewed

---

## 4. Learning interpretation

This exercise helped practice how to:

- read Nmap output
- identify service and port patterns
- review web scanner output
- separate scanner indicators from confirmed findings
- document learning in a professional format

---

## 5. Important note

The items reported by the scanner were not independently validated as real vulnerabilities against a production environment. They are useful as learning examples and should not be treated as confirmed exploitation findings.

---

## 6. Next steps

- review scanner output carefully
- validate possible findings before treating them as vulnerabilities
- practice defensive monitoring for reconnaisssance activity
- continue building portfolio notes and technical reports
- compare scanner findings with Blue Team detection methods

---

## 7. Summary

This was a good beginner-friendly recon exercise. It helped build structure, observation skills, and documentation habits without overclaiming results. The value here is in the learning process and the ability to communicate results carefully.
