# Commands Used in ScanMe Recon Lab

WARNING: Only run these commands against approved targets or legal training environments. Do not use Nmap, Nikto, or other scanning tools against systems without explicit permission. This file is part of a learning and documentation portfolio.

# Basic Nmap Scan
nmap scanme.nmap.org

# Service Version Scan
nmap -sV -p 22,80,9929,31337 scanme.nmap.org

# Aggressive Scan
nmap -A scanme.nmap.org

# Nikto Web Vulnerability Scan
nikto -h scanme.nmap.org

# Test XSS Reflection
curl "http://scanme.nmap.org/?mod=<script>alert('XSS')</script>"

# Test SQL Debug Parameter
curl "http://scanme.nmap.org/?sql_debug=1"

# Fingerprint Apache Headers
nmap --script http-server-header -p 80 scanme.nmap.org
