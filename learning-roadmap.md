# Cybersecurity Learning Roadmap

This roadmap is a flexible guide for my cybersecurity studies. It is designed for steady progress in small steps while balancing school, work, and family responsibilities.

## How to use this roadmap

- Focus on one small topic at a time.
- Practice only in approved labs or authorized environments.
- Write down what I learned, what confused me, and what I want to review.
- Do not rush to advanced tools before understanding the basics.
- Update this file when my goals change.

## Phase 1: Foundations

- [ ] Learn basic Linux navigation and file management
- [ ] Practice permissions, users, and processes
- [ ] Learn common networking terms: IP address, port, protocol, DNS, HTTP, and SSH
- [ ] Practice reading simple command output
- [ ] Learn basic Git and GitHub vocabulary
- [ ] Build a habit of writing short study notes

## Phase 2: Safe Security Practice

- [ ] Use Nmap only in an approved lab or legal practice environment
- [ ] Identify open ports and services at a beginner level
- [ ] Learn the difference between an observation, an indicator, and a confirmed finding
- [ ] Practice reviewing logs for timestamps, users, sources, and actions
- [ ] Learn the basics of packet capture and filtering
- [ ] Document each exercise with purpose, steps, observations, and lessons learned

## Phase 3: Defensive and Purple Team Skills

- [ ] Identify what defensive evidence a scan may create
- [ ] Connect an activity to a possible detection idea
- [ ] Practice writing a simple incident timeline
- [ ] Describe a recommended defensive action in plain language
- [ ] Complete one small attack-and-detect exercise in a controlled lab
- [ ] Review the exercise and record what I would improve

## Phase 4: Portfolio Development

- [ ] Keep each project in a clear folder
- [ ] Add a short README to each completed lab
- [ ] Remove secrets, private information, and unsupported claims
- [ ] Explain tools and results in beginner-friendly language
- [ ] Add evidence only when it is safe and authorized to publish
- [ ] Review the portfolio monthly instead of trying to update everything at once

## Phase 5: Career Preparation

- [ ] Keep a current resume
- [ ] Record courses, labs, certifications, and school projects
- [ ] Ask an instructor or career advisor for feedback
- [ ] Explore internships, entry-level security roles, and scholarships
- [ ] Learn basic professional communication and report writing
- [ ] Continue growing before offering security services independently

## Current priority

My current priority is to understand the fundamentals and finish one clearly documented lab at a time. I do not need to build a blockchain, run autonomous agents, or launch a business before I have a strong foundation.

## Safety reminder

This portfolio is for education and authorized practice. Never scan, test, access, or attempt to recover assets from systems, accounts, wallets, or networks without permission. Never publish passwords, seed phrases, private keys, API keys, tokens, or personal identifying information.
