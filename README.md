# 🔥 Phoenix Cybersecurity Portfolio

> **Resilience. Learning. Recovery. Renewal.**

Welcome to my cybersecurity learning portfolio.

I am a Miami Dade College cybersecurity student building practical foundations in Linux, networking, defensive monitoring, ethical security practice, and technical documentation. This repository records my progress one small, understandable project at a time.

## 🌟 About this portfolio

The Phoenix represents resilience and renewal. This portfolio is a personal learning space—not a finished security company, production blockchain, or guaranteed security service.

My goal is to develop real skills, document my learning honestly, and prepare for future education and career opportunities while balancing work and family responsibilities.

- GitHub, repositories, branches, and safe project organization

All activities documented here are for education and authorized practice only. Security tools must be used only against systems I own, approved school labs, legal training targets, or systems for which I have explicit permission.
